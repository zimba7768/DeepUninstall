Leftover Test App
=================

This is not a real program. It is a test fixture for DeepUninstall
(https://github.com/zimba7768/DeepUninstall).

Its uninstaller deliberately leaves files, folders, registry entries, a startup
entry, a file type and a desktop shortcut behind. Uninstall it with DeepUninstall
to check that all of them are found and removed.

It is safe to delete.
